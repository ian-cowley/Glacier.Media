# Glacier.Media

Pure C# .NET 10 generative multimodal media engine featuring FLUX.1 Flow-Matching DiT (with pure-C# CLIP-L BPE & T5-XXL SentencePiece encoders), Wan 2.1 3D Spatio-Temporal Video DiT & 3D Causal VAE, KittenTTS neural speech synthesis (StyleTTS 2 / ALBERT / HiFi-GAN), procedural Liljencrants-Fant glottal formant TTS (`ProceduralFormantTtsEngine` / `KokoroTtsEngine` presets), OpenAI-compatible HTTP Whisper STT client/proxy (`WhisperEngine`), and 2D/3D spatial multimodal projectors.

## Installation

```bash
dotnet add package Glacier.Media
```
