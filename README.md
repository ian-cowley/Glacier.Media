# Glacier.Media

Pure C# .NET 10 generative multimodal media engine featuring FLUX.1 Flow-Matching DiT, Wan 2.1 3D Spatio-Temporal Video DiT, KittenTTS and Kokoro neural speech synthesis, Whisper STT, and 2D spatial multimodal projectors.

## Installation

```bash
dotnet add package Glacier.Media
```
